## 项目简介

「黄地橙丰」是一款面向**厦门集美黄地村脐橙产业**的产销一体化微信小程序，将 **AI 农技服务、线上零售、IP 文创、数字化台账**四位一体打通，覆盖"生产管护 → 店铺经营 → 线上零售 → 文创消费"完整链路。

## 核心功能

- **AI 农技助手**：文字咨询 + 实景图片识别双模式，基于智谱清言 GLM-4V 多模态大模型 + 脐橙专属 RAG 知识库，输出标准化管护方案
- **消费者端**：脐橙选购、IP 文创周边、购物车、订单管理
- **种植户端**：商品发布、订单管理、农事记录、园区环境监测、果树生长周期报告
- **数字化台账**：施肥/浇水/病虫害防治等标准化农事档案

## 技术架构

- 前端：微信小程序原生框架（组件化开发）
- 后端：轻量化云数据库 + 网关适配层
- AI：智谱清言 GLM-4V 多模态大模型 + 本地 RAG 行业知识库 + 农业专用 Prompt 工程

## 运行说明

1. 使用微信开发者工具打开 `miniprogram` 目录
2. 在 `utils/aiAPI.js` 中填入你自己的智谱开放平台 API Key（示例已脱敏）
3. 编译运行即可体验
